About Shared Platform Mode

Configure your platform's shared SAS API keys here. Tenants who choose "Shared Platform" mode will use these keys with their own unique User ID / Customer ID for tenant isolation.

This allows you to share one SAS subscription across all tenants, significantly reducing costs while maintaining proper tenant isolation through User IDs and Customer IDs.
