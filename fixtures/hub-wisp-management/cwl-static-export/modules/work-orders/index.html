Welcome to Work Order Creation! 📋

This wizard will guide you through creating a work order or ticket.

What You'll Do:

  • ✅ Select work order type
  • ✅ Identify affected sites/equipment/customers
  • ✅ Enter details and description
  • ✅ Set priority and SLA
  • ✅ Assign technician (optional)
  • ✅ Attach files/photos

Work Order Types:

  • Installation: New equipment installation
  • Repair: Fix broken equipment
  • Maintenance: Scheduled maintenance
  • Upgrade: Equipment upgrade
  • Removal: Remove equipment
  • Troubleshoot: Diagnose issues
  • Inspection: Site inspection
