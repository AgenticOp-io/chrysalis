Voice / SIP & UC

Tenant-scoped numbers, carrier accounts, E911, and porting. Webhook ingress: POST /api/voice/webhooks/:provider (HMAC when VOICE_WEBHOOK_SECRET is set). Customer records link via customerId (same id as Customers module).

Service locations (E911 / geocode)

Use the same customerId as the Customers module to tie addresses together. Coverage Map opens centered on coordinates when available.
