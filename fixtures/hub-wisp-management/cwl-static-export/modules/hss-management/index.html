Bulk Import Subscribers

Import Instructions:

  1. Download the CSV template above
  2. Fill in subscriber details (IMSI, Ki, OPc are required)
  3. Upload the CSV file below
  4. Review the preview and confirm import

Required Fields:

  • imsi: 15-digit IMSI (e.g., 310150123456789)
  • ki: 32-character hex key (e.g., 00112233...EEFF)
  • opc: 32-character hex OP/OPc key

Optional Fields:

  • msisdn: Phone number
  • full_name: Subscriber name
  • qci: QoS Class Identifier (default: 9)
  • group_id: Subscriber group
  • bandwidth_plan_id: Bandwidth plan

Define download and upload limits (Mbps) for subscriber groups. Groups can then be assigned to this plan.

Create a Subscriber Group

Groups organize subscribers and can be linked to a bandwidth plan. New subscribers can be assigned to this group.

You will:

  • Enter a group name and optional description
  • Optionally assign a bandwidth plan
  • Set default APN and QCI for the group
