How conversion runs

Translate-only method — no demo façades, no invented widgets.

  1. InventoryRoutes, adapters, gaps from the real origin.
  2. LiftOrigin idioms → WebIR; holes stay honest.
  3. EmitTarget stack handlers from WebIR, not stubs.
  4. ProveOracle replay, origin compare, operator evidence.
